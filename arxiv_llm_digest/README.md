# 生物学与AI论文分析器 (Bio-AI Paper Analyzer)

一个专门用于分析生物学与深度学习交叉研究论文的智能工具，能够从Crossref数据库中搜索、分析和总结相关学术论文。

## 🌟 主要特性

### 🔬 专业分析框架
- **跨学科专家视角**：以计算生物学、生物信息学和深度学习专家的角度分析论文
- **多维度评估**：
  - 新颖性评分 (1-5)：从渐进式改进到范式转换突破
  - 生物学影响评分 (1-5)：推进生物学知识或临床应用的潜力
  - 技术创新评分 (1-5)：新颖的计算/AI方法论贡献

### 🤖 智能模型支持
- **QWen系列模型**：包括最新的思维链模型和长上下文模型
- **DeepSeek系列模型**：高性能推理和分析能力
- **自动模型选择**：根据任务需求智能选择最适合的模型

### 🔍 精准搜索功能
- **生物学+AI交叉搜索**：专门优化的搜索关键词
- **时间范围控制**：可设置搜索最近N天的论文
- **质量过滤**：只搜索包含摘要的高质量论文

### 🌐 多语言支持
- **中英文双语**：支持中文和英文输出
- **智能翻译**：自动翻译英文摘要为学术中文
- **本地化界面**：完全中文化的用户界面

## 🚀 快速开始

### 环境要求
- Python 3.8+
- PySide6 (GUI框架)
- OpenAI API兼容客户端
- Crossref API客户端

### 安装依赖
```bash
pip install -r requirements.txt
```

### 获取API密钥
1. 注册SiliconFlow账户：https://siliconflow.cn
2. 获取API密钥
3. 在GUI中输入API密钥

### 运行程序

#### 图形界面模式
```bash
python bio_ai_gui.py
```

#### 命令行模式
```bash
python bio_ai_paper_analyzer.py --query "computational biology deep learning" --days 7 --max-results 20
```

## 🔧 配置选项

### 搜索参数
- **搜索关键词**：如"protein structure prediction", "genomics deep learning"
- **搜索天数**：0表示无限制，其他数字表示最近N天
- **最大结果数**：控制返回的论文数量

### 模型选择
- **QWen系列**：适合复杂推理和长文本分析
- **DeepSeek系列**：适合深度分析和创新评估

### 输出格式
- **Markdown报告**：结构化的分析报告
- **多维度评分**：量化的评估指标
- **中英文摘要**：便于不同语言背景的用户

## 📊 输出示例

生成的报告包含：
- 论文基本信息（标题、作者、期刊、年份）
- 多维度评分（新颖性、生物学影响、技术创新）
